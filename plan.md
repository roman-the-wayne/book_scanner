# Роудмап развития проекта «Book Scanner & Library»

Файл сформирован по результатам брейншторма и структурирован по приоритетам реализации.

---

## 📊 Приоритеты и Этапы Разработки (Roadmap)

### 🔴 Фаза 1: Высокий приоритет (MVP Core & Usability)
*Функционал, критичный для базового удобства пользователя и организации библиотеки.*

1. **Экран деталей книги («Посмотреть данные» вместо прямого редактирования)**
   - Создание отдельной карточки книги (`BookDetailsPage`).
   - Отображение подробных сведений, крупной обложки, описания, статусов и заметок.
   - Переход к редактированию только по кнопке «Редактировать» внутри карточки.
2. **Адаптивная верстка длинных названий (UI Fix)**
   - Перенос длинных названий книг на несколько строк без обрезки текста в списках и карточках.
3. **Поиск, фильтрация и сортировка в локальной библиотеке**
   - Поисковая строка по локальной базе (название, автор, жанр).
   - Сортировка: по дате добавления, названию, автору, году.
   - Быстрые фильтры: «Прочитано / Не прочитано», «В долгу».
4. **Статусы книги и рейтинг**
   - Статус прочтения: «Прочитано» / «Не прочитано».
   - Статус использования: «У меня» / «Отдал в долг» (с указанием кому отдал и даты).
   - Рейтинг книги (1–5 звёзд).
5. **Поддержка Тёмной и Светлой темы (Dark / Light Theme)**
   - Полноценная настройка `ThemeData` (Material 3) с возможностью автоматического переключения или выбора в настройках.

---

### 🟡 Фаза 2: Средний приоритет (Расширенное распознавание и облако)

6. **Расширенные метаданные книги**
   - Поля: Жанр, Издательство, Город издания, Количество страниц, ISBN, УДК / ББК.
   - Настройка промпта AI (Mistral) для извлечения этих данных с первой/титульной страницы при сканировании.
7. **Автоматическое обогащение данных при сканировании (API Enrich)**
   - Проверка и дополнение сведений о книге через внешние API (OpenLibrary) сразу при сканировании или по желанию пользователя.
8. **Вишлист (Wishlist / «Хочу купить»)**
   - Отдельный раздел/список книг, которые пользователь планирует приобрести.
   - Возможность быстрой отправки отсканированной книги в Вишлист вместо Библиотеки.
9. **Облачное хранение и синхронизация (Cloud Sync)**
   - Интеграция с Supabase / Firebase для хранения данных пользователя и резервного копирования библиотеки.

---

### 🟢 Фаза 3: Низкий приоритет / Долгосрочные идеи (Integrations & Expansion)

10. **Мониторинг цен на маркетплейсах (Ozon, WB, Литрес)**
    - Поиск цен на книгу из Вишлиста на маркетплейсах и книжных магазинах.
    - Уведомления об акциях и скидках.
11. **Интеграция с библиотечными системами (OPAC / ИРБИС)**
    - Проверка наличия книги в городских/публичных библиотеках.
12. **Модуль «Умный холодильник» (Smart Fridge Analytics)**
    - *Перспективное ответвление:* Выделение технологии распознавания в отдельный модуль для сканирования содержимого холодильника, учета продуктов и формирования рецептов.

## 🎨 Дизайн и UI/UX рекомендации (AI Design Guidelines)

1. **Цветовая палитра:**
   - *Светлая тема:* Теплые бумажные/кремовые фоновые тона (`#FDFBF7`), глубокий индиго/серо-синий для акцентов и читабельного текста.
   - *Тёмная тема:* Глубокий графитовый фон (`#121212` / `#1E1E1E`), мягкие контрастные цвета для текста без выжигания глаз.
2. **Карточки книг:**
   - Крупные обложки с мягкими скруглениями углов (`BorderRadius.circular(12)`).
   - Цветные аккуратные бейджи для статусов (зелёный — прочитано, оранжевый — отдано в долг).
3. **Навигация:**
   - Минималистичный Material 3 `NavigationBar` снизу с плавными переходами.
